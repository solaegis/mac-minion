Troubleshooting

"MacMinion can't be opened" the first time

It isn't notarized by Apple. Right-click the app > Open, or System Settings > Privacy & Security > Open Anyway. See Install.

It keeps asking for access to Documents

  • Downloaded releases are all signed with the same certificate, so macOS remembers your answer across updates. Choose Allow once.
  • Builds you make yourself signed ad hoc are a new app every time. Run tools/make-signing-identity.sh once; see Build from source.
  • To ask again from scratch: tccutil reset SystemPolicyDocumentsFolder com.solaegis.macminion.

Installed is empty or shows 0 addons

  • Check Settings > General points at the right AddOns folder.
  • If the toolbar says "Can't read the AddOns folder", allow Documents access in System Settings > Privacy & Security > Files and Folders.
  • Right after launch the app is still reading the folder and the catalog; give it a few seconds.

"Version unknown" on an addon

It was installed by hand, so no version is recorded. Choose Reinstall once; after that it's tracked.

An addon is under "Not on ESOUI"

No ESOUI entry lists that folder: it's yours, from another site, or copied by hand. MacMinion can't update it, but leaves it alone.

MacMinion doesn't find its own updates

  • MacMinion > Check for MacMinion Updates… shows any error.
  • Builds you make yourself have a higher build number than releases, so they aren't offered updates.
  • The feed is appcast.xml; it should list the latest release.

AI summaries time out or fail

  • Ollama must be running. Settings > AI > Test Connection shows the error.
  • Large models are slow to load the first time. Use the recommended model, or Benchmark Top Models.
  • Claude needs a valid API key; the error message says what's wrong.
