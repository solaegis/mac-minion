Command line

macminion runs commands in the MacMinion app, so the window updates as they run. If the app is closed, a command opens it in the background.

Basics

  • Put it on your PATH: see Install.
  • Add --json for output scripts and AI agents can read. Errors come back as {"error": {"code", "message"}} with a nonzero exit code.
  • Addons are named by their ESOUI id: the number in esoui.com/downloads/info<id>.
  • Commands that remove things only report what they would do until you add --yes.
  • macminion help lists everything; macminion help <command> shows one.
  • macminion mcp serves the same commands to MCP clients such as Claude Desktop.
macminion status --json
macminion addons list --status update --json
macminion updates install --json

Status and catalog

macminion status · reads only

Show the AddOns folder, catalog, and counts of installed addons and updates.

macminion status --json

macminion folders list · reads only

List folders in AddOns that no ESOUI entry lists (your own or hand-copied addons).

macminion folders list --json

macminion catalog search · reads only

Search the ESOUI catalog by name or author, like Find More: installed addons are left out unless --installed.

OptionTypeMeaning
--categoryintegeronly this category id (see `macminion categories list`)
--compatiblebooleanonly addons that list the current game version
--installedbooleaninclude installed addons (Find More leaves them out)
--limitintegerat most this many (default 25)
--no-librariesbooleanleave libraries out
--offsetintegerskip this many, for the next page
--querystringtext to find; leave out to browse
--ratingstringonly: up, down, unrated, or not-down
--sortstringdownloads, monthly, favorites, newest, or name (default downloads)
--updatedstringonly updated within: week, month, quarter, or year
macminion catalog search "master merchant" --limit 5 --json

macminion categories list · reads only

List ESOUI categories and their ids.

macminion categories list --json

macminion history list · reads only

List recent installs, updates, and removals, newest first.

OptionTypeMeaning

--offsetintegerskip this many, for the next page

OptionTypeMeaning
