Libraries for installed addons

MacMinion reads every addon's manifest. A library that's bundled inside another addon's folder counts as installed, because the game loads it from there. Obsolete libraries such as LibStub are left out.

  • Install one, or Install All.
  • A thumbs down hides an optional library for good. A required one keeps showing, whatever its rating.

Arrange the Overview

Choose Customize Overview in the toolbar (or Settings > Layout > Customize Overview…). Check the sections to show and drag them into order. You can also right-click any section for Move Up, Move Down, or Hide. Reset to Default brings everything back.
