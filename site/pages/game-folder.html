Game Folder

Everything beside AddOns in ~/Documents/Elder Scrolls Online/live: which addons keep settings for which characters, what each SavedVariables file holds, what looks wrong, and the game's own settings files.

Game Folder has four tabs: Characters, Inspector, Problems, and Game Settings (⌃⌘1 through ⌃⌘4). Show Game Folder in Finder is ⌥⌘G. From the command line, macminion sv covers files, find, problems, and space totals; see Command line.

Characters

Game Folder opens on Characters: a grid of the addons that keep settings for each of your characters. Darker squares hold more settings; an outlined square, with a number, means some are set differently from your other characters. Click to dig down: a character shows their addons around them and what's set differently for them; a square shows that character's settings in that addon, odd ones highlighted beside the usual value; a setting shows every value it has across your characters, as bars, with who has each. An account over the grid opens that account and its megaservers. The path bar or ⌘[ climbs back out. Only the settings addons save are read, never their code.

Compare With… on a character, or Compare Characters… (⌃⌘C), puts two characters side by side: every setting where they differ, then what only one of them has. From a character inside one addon, Compare With… scopes the comparison to that addon's file so Clone and Clone all change only those differences. Save and copy can be undone with ⌘Z.

With MacMinion Companion installed, character cards can also show class, level, and champion points from what the companion recorded.

Inspector

Pick a SavedVariables file on the left to see what it stores. Files list largest or by name, with the addon each belongs to:

  • An addon's name: an installed addon saves here. Addons inside other addons count too, up to three folders deep, as the game loads them (LibGuildStore's GS00Data to GS17Data, HarvestMap's HarvestMapAD).
  • The game: ZO_*.lua, the game's own interface settings. Never cleaned up.
  • No installed addon: left behind by an addon you removed.
  • Your copy: a copy of a .lua file, like pChat.lua.bak or HarvestMap.lua~, or a folder.
  • Not saved by the game: anything else, like the README of a git repository you keep here. Left alone.

The tree shows Key, Value, and Size. The server, account, and character levels are labeled, and IDs get names:

  • Characters from the game's own ZO_Ingame.lua and from addons; an ID no file names reads Unknown character.
  • Accounts, marked yours when your own data sits under them.
  • Items from item links (level, style, bound, crafted), with the set from LibSets.
  • Sets, zones, and quests from LibSets, LibZone, and LibQuestData, read from their data files without running them.
  • LibGuildStore sales: the numbers in each sale become the item, the buyer or seller, and the guild.

The Inspector opens on Settings: the addon's saved settings as you'd read them, a section for every character and one for settings all your characters share. On and off are switches, colors are swatches, item links are item tags with their set, times are dates, money is gold, and IDs are names. Tree (⌥⌘V) shows every key and value as stored. Right-click a setting to see it in the tree.

Double-click a table (or ⌘↓) to show only its entries; the path bar or ⌘↑ goes back up. The Inspector menu also has Copy Path (⌥⌘C), Copy Value (⇧⌘C), Show Raw (⌥⌘R), and Look Up on UESP (⌥⌘L), which opens the page in your browser. A file that ends early or has a mistake shows where, with everything before it still browsable.

Find (⌘F) takes a name or an ID, like Masisi, @Paltop, Glenumbra, or 96175, and lists every place it appears in all your SavedVariables, grouped by file. Find Everywhere (⇧⌘F) does the same for the selected row. Double-click a place to open it in the tree; Done or Escape goes back. A character's connections map shows the files and things stored with them; follow a node to dig further.

Problems

Every SavedVariables file is checked when the page opens; the tab shows how many findings there are. Errors come first:

  • Ends early or Can't be read: the game stopped writing the file, or it has a mistake. The addon may lose its settings; a backup can bring them back.
  • Variable not declared: left by an older version of the addon. The game never loads it.
  • Variable not saved: the file has none of the variables its addon declares.
  • Mixed types: a setting that is a number for most characters and a string for one, which can make an addon fail.
  • Long list: 5,000 entries or more, like a log or history that grows every session.
  • Large file: over 5 MB. The game reads every file at each login and reload.
  • Clean up: files no installed addon uses, copies of .lua files, or data for an unknown character.

Double-click a problem to see it in the Inspector. Choose Clean Up… (⇧⌘T) or Clean Up All… on Problems to move unused files and copies to the Trash (Problems lists the same files). Select findings and act on one at a time when you only want some.

Before anything goes to the Trash, MacMinion makes a backup of SavedVariables and the settings files.

Quit the game first: it rewrites these files when it quits. MacMinion won't change anything while it runs.

Game Settings

Game Settings shows UserSettings.txt, AddOnSettings.txt, and MachineSettings.txt as forms. Each field uses an editor that fits its value: switches for on/off, number fields, a color well for AARRGGBB colors, width × height for resolution, pickers for realm, language, and API version (named by update), and text for the rest. AddOnSettings lists its headers, then each character's addons as switches.

Edits are a draft until you Save (⌘S) or Revert. Save refuses while ESO runs, backs up first, and rewrites only the changed lines, each with its own line ending. Backups include MachineSettings.txt. Curated high-value keys show hover help (an info mark) for what the setting and its options mean; unknown keys have no tip.
