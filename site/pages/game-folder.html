Game Folder

Everything beside AddOns in ~/Documents/Elder Scrolls Online/live: what each item is, how big it is, and the SavedVariables files no installed addon uses any more.

Characters and Addons

Game Folder opens on Characters: a grid of the addons that keep settings for each of your characters. Darker squares hold more settings; an outlined square, with a number, means some are set differently from your other characters. Click to dig down: a character shows their addons around them and what's set differently for them; a square shows that character's settings in that addon, odd ones highlighted beside the usual value; a setting shows every value it has across your characters, as bars, with who has each. The path bar or ⌘[ climbs back out. Compare With… on a character, or Compare Characters… (⌃⌘3), puts two characters side by side: every setting where they differ, then what only one of them has. Addons starts from each addon instead: what every character shares, what's the same on all of them, and what's set differently. Only the settings addons save are read, never their code.

Files

Files holds the folder itself, the SavedVariables list, and Space.

Folder

Each item the game makes, with its size and when it last changed: SavedVariables, AddOnSettings.txt, UserSettings.txt, the graphics caches, GuildHistory, Logs, Errors, and Screenshots.

Your Own Copies lists the files and folders the game doesn't make, like AddOnSettings.txt.bak-20260829 or a SavedVariables.bak folder saved before an edit. Move one or all of them to the Trash.

SavedVariables

Every file in SavedVariables, largest first, with the addon it belongs to:

  • An addon's name: an installed addon saves here. Addons inside other addons count too, up to three folders deep, as the game loads them (LibGuildStore's GS00Data to GS17Data, HarvestMap's HarvestMapAD).
  • The game: ZO_*.lua, the game's own interface settings. Never cleaned up.
  • No installed addon: left behind by an addon you removed.
  • Your copy: a copy of a .lua file, like pChat.lua.bak or HarvestMap.lua~, or a folder.
  • Not saved by the game: anything else, like the README of a git repository you keep here. Left alone.

Choose Clean Up… (⇧⌘T) to move every file with no installed addon, and every copy, to the Trash. Select files and Control-click to move only those.

Before anything goes to the Trash, MacMinion makes a backup of SavedVariables and the settings files.

Quit the game first: it rewrites these files when it quits. MacMinion won't change anything while it runs.

Inspector

Pick a SavedVariables file (or double-click one in SavedVariables) to see what it stores, as a tree with Key, Value, and Size. The server, account, and character levels are labeled, and IDs get names:

  • Characters from the game's own ZO_Ingame.lua and from addons; an ID no file names reads Unknown character.
  • Accounts, marked yours when your own data sits under them.
  • Items from item links (level, style, bound, crafted), with the set from LibSets.
  • Sets, zones, and quests from LibSets, LibZone, and LibQuestData, read from their data files without running them.
  • LibGuildStore sales: the numbers in each sale become the item, the buyer or seller, and the guild.

The Inspector opens on Settings: the addon's saved settings as you'd read them, a section for every character and one for settings all your characters share. On and off are switches, colors are swatches, item links are item tags with their set, times are dates, money is gold, and IDs are names. Tree (⌥⌘V) shows every key and value as stored. Right-click a setting to see it in the tree.

Double-click a table (or ⌘↓) to show only its entries; the path bar or ⌘↑ goes back up. The Inspector menu also has Copy Path (⌥⌘C), Copy Value (⇧⌘C), Show Raw (⌥⌘R), and Look Up on UESP (⌥⌘L), which opens the page in your browser. A file that ends early or has a mistake shows where, with everything before it still browsable.

Find (⌘F) takes a name or an ID, like Masisi, @Paltop, Glenumbra, or 96175, and lists every place it appears in all your SavedVariables, grouped by file. Find Everywhere (⇧⌘F) does the same for the selected row. Double-click a place to open it in the tree; Done or Escape goes back.

Problems

Every SavedVariables file is checked when the page opens; the tab shows how many problems there are. Errors come first:

  • Ends early or Can't be read: the game stopped writing the file, or it has a mistake. The addon may lose its settings; a backup can bring them back.
  • Variable not declared: left by an older version of the addon. The game never loads it.
  • Variable not saved: the file has none of the variables its addon declares.
  • Mixed types: a setting that is a number for most characters and a string for one, which can make an addon fail.
  • Long list: 5,000 entries or more, like a log or history that grows every session.
  • Large file: over 5 MB. The game reads every file at each login and reload.

Double-click a problem to see it in the Inspector. Show Problems is ⌥⌘P.

Space

What takes space in your SavedVariables. Map comes first: a tile per addon, sized by how much it saves and colored by what it holds (prices and sales, map data, logs that grow, the game's own, and settings). Click a tile to zoom in, to an addon's files, then the tables inside; a tile you can't zoom into opens in the Inspector. The path bar or ⌘- zooms out. The other groups list the same space, largest first, each with a bar for its share:

  • Biggest Tables across all files. A table whose space is mostly one child shows the child instead.
  • Characters, as cards: name, server, and how much addons keep about each. With MacMinion Companion installed, cards also show class, level, and champion points. Click a card to see its data by addon and open any of it in the Inspector. Characters no file names show apart: deleted or renamed.
  • Accounts: yours, then other players your addons keep data about, like guild members and traders.
  • Servers: NA, EU, and Default, which holds data saved before the split and settings both share.
  • Files.

Double-click a table or file to open it in the Inspector, or a character or account to find everywhere it appears. Show Space is ⌥⌘S. Nothing here changes your files.

Show Game Folder in Finder is ⌥⌘G.
