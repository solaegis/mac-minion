Install

Download a release, or build it yourself. Either way it lives in Applications and keeps itself up to date.

Requirements

  • macOS 26 or later, Apple silicon.
  • The Elder Scrolls Online, with its AddOns folder (by default ~/Documents/Elder Scrolls Online/live/AddOns).
  • To build from source: Xcode 26 or later (Swift 6.2).

Download

  1. Open the latest release and download MacMinion-version-macos-arm64.zip.
  2. Unzip it and drag MacMinion.app into /Applications or ~/Applications.
  3. Open it the first time with right-click > Open, then Open again.
  4. When macOS asks whether MacMinion may access files in your Documents folder, choose Allow: that's where the AddOns folder is.

Why the first-open step? MacMinion is signed with its own certificate, not an Apple Developer ID, and isn't notarized, so Gatekeeper asks once for a download from the internet. If macOS still blocks it, use System Settings > Privacy & Security > Open Anyway, or run:

xattr -cr ~/Applications/MacMinion.app
open ~/Applications/MacMinion.app

After that, updates install through MacMinion itself and are checked with their own signature (see Updating MacMinion).

Put the command line on your PATH

mkdir -p ~/.local/bin
ln -sf ~/Applications/MacMinion.app/Contents/MacOS/MacMinion ~/.local/bin/macminion
macminion help

Use /Applications in the path if you installed there. See Command line.

Build from source

git clone https://github.com/solaegis/mac-minion.git
cd mac-minion
./build.sh --open

That builds ~/Applications/MacMinion.app and links macminion into ~/.local/bin.

Builds signed ad hoc are a new app to macOS each time, so it asks for Documents access after every build. Create a local signing identity once and build.sh signs with it from then on:

tools/make-signing-identity.sh

A build you make yourself has a higher build number than any release, so MacMinion doesn't offer it updates.

Uninstall

  1. Quit MacMinion (menu bar item > Quit, or ⌘Q) and move it to the Trash.
  2. Optionally remove its data: ~/Library/Application Support/MacMinion and the com.solaegis.macminion preferences.
  3. Your addons, SavedVariables, and backups stay where they are.
