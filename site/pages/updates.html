Updates

Two kinds: your addons, from ESOUI, and MacMinion itself, from GitHub.

Addon updates

  • Update on a card or row updates one addon. Update All (⌘U) updates every addon that has one, a few at a time.
  • Each download is checked against ESOUI's MD5 checksum before anything changes. If any step fails, the old folders are put back.
  • Check for Updates (⌘R) downloads the catalog again. MacMinion also checks on its own, once a day by default.
  • Ignore Updates (in an addon's menu) keeps an addon at its version; Update All skips it.
  • The menu bar item shows the number of updates and offers Update All.

Settings

In Settings > Updates: how often to check, whether to install updates automatically, how many downloads run at once, and a notification when updates are ready.

If you still have Minion, turn off its auto-update so the two apps don't both write to AddOns.

Updating MacMinion

MacMinion updates itself with Sparkle. It checks once a day, and MacMinion > Check for MacMinion Updates… checks now.

  • Each release is a zip on GitHub Releases, listed in an update feed at solaegis.github.io/mac-minion/appcast.xml.
  • Every update is signed with an EdDSA key. MacMinion has the public key built in and installs an update only when its signature matches. Apple notarization isn't part of this; the signature is what makes an update trustworthy.
  • Releases are signed with the same certificate every time, so macOS keeps your permissions (such as Documents access) across updates.
  • Settings > Updates > MacMinion shows your version and lets you turn automatic checks and automatic installs on or off.
