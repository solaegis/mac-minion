# Glossary

- **Addon**: one ESOUI catalog entry (one UID). It can install several folders.
- **Folder**: one directory under the AddOns folder.
- **AddOns folder**: `~/Documents/Elder Scrolls Online/live/AddOns` by default.
- **Catalog**: the cached `filelist.json` from ESOUI.
- **Installed**: an addon whose folders exist and are matched to a UID.
- **Unmatched**: a folder with no catalog match (local or dev addons).
- **Update available**: the catalog's UIVersion/UIDate is newer than the recorded install.
- **Ignore updates**: skip this addon in Update All and in the update count.
- **Library**: an addon in category 53 ("Libraries").
